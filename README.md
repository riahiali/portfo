# Ali Riahi portfolio — starter package

This is a polished static-site starting point and preliminary audit package, not a completed or deployed portfolio.

## Run locally
Open `index.html` in a browser. For a local server, run `python -m http.server 8000` from this directory and visit `http://localhost:8000`.

## Before production
- Replace `hello@example.com` with a public contact address.
- Supply the original French CV PDF so the English translation can be completed faithfully.
- Complete the source-level audit for all 18 repositories and inspect local project directories.
- Replace provisional project rankings and conceptual diagrams only after implementation verification.
- Run accessibility, mobile, link, build and browser tests.
- Deploy only after the owner authorizes the target hosting account.

See `docs/repository-audit.md` and `docs/visual-asset-inventory.md`.
