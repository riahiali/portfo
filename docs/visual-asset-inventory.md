## Required before production
- Save real screenshots only after running the respective apps and verifying the screens.
- For backend-only projects, prefer a source-grounded architecture diagram or API sequence illustration.
- For firmware/IoT, use the verified hardware, communication protocol and actual system boundaries.
- Store finalized assets under `public/images/projects/` and update this inventory with filename, project, provenance and verification status.
